# Student source coverage (required harvesting scope)

This is the acceptance inventory for the student's request to bring school data into Sorta automatically. A source is **complete** only after a real signed-in capture, an idempotent repeat, and a browser check of the resulting records. Code, a visible tab, or a partial list alone is not proof. The source text is the user's attached `Pasted text.txt`; this document is a tracking aid, not a replacement for that request.

Current live evidence, 2026-10-05: Teams Assignments list/detail snapshots, rendered posts across seven classes and 13 class channels, InSchool timetable/attendance/assessment snapshots, and school files from Teams Shared channels and rendered posts have been imported at least once. The first bounded school-file run at `0e64e34` captured 51 files: 19 unchanged PowerPoint occurrences and 32 newly imported PDF/Word occurrences, including five documents linked from rendered posts. Text extraction succeeded for all 32 new documents; one earlier PowerPoint original has no embedded text. At `c986f51`, Brain grouped verified byte-identical PPTX/PDF/Word originals without deleting source records; a grouped Teams Word material exposed both Shared and Posts source locations and retained its original-download link. A previous file repeat exposed a SharePoint folder-transition race; another failed on an invalid download, so `10f8fe2` added bounded backoff and source-position failure diagnostics. A later real file repeat captured all 51 unchanged. At `147af80`, a multi-channel post run found 74 rendered posts, including four new non-General records; the repeat found all 74 unchanged. At `c1a0b7b`, bounded upward scrolling found 102 post records in the same seven classes and 13 channels, creating 28 older posts; a real repeat found all 102 unchanged. In the live browser, Brain showed 194 material cards and 212 source records, and an opened newly imported post retained its class and channel. The seventh probed Classwork view displayed a Microsoft embedded “Oops” page with no collectable rows, not proof that it is empty. Future unattended execution of these broadened collectors remains to be observed. No row below is claimed complete.

Cross-source change detection is also required: edits to old posts/assignments, attached files added later, comments and mentions inside Office documents, returned feedback, moved calendar events, post-lesson chat/recordings, silent OneNote page distribution and unannounced channel files. A successful one-time import does not satisfy this requirement.

The user-facing result should normalize evidence into **TASK, DEADLINE, ANNOUNCEMENT, MESSAGE, EVENT, RESOURCE, FEEDBACK, CHANGE**. Today should show the actionable item and what changed, with a source link and uncertainty where needed; it should not expose a data-entry cockpit or claim school submission/grades that were not observed. Each collector must keep source identity, capture time, original evidence, update/deletion semantics, and an honest coverage/last-success state.

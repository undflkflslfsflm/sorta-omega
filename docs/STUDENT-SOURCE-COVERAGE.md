# Student source coverage (required harvesting scope)

This is the acceptance inventory for the student's request to bring school data into Sorta automatically. A source is **complete** only after a real signed-in capture, an idempotent repeat, and a browser check of the resulting records. Code, a visible tab, or a partial list alone is not proof. The source text is the user's attached `Pasted text.txt`; this document is a tracking aid, not a replacement for that request.

Current live evidence, 2026-10-06: Teams Assignments list/detail snapshots, rendered posts across seven classes and 13 class channels, InSchool timetable/attendance/assessment snapshots, and school files from Teams Shared channels and rendered posts have been imported at least once. Cross-source change detection is also required: edits to old posts/assignments, attached files added later, comments and mentions inside Office documents, returned feedback, moved calendar events, post-lesson chat/recordings, silent OneNote page distribution and unannounced channel files. A successful one-time import does not satisfy this requirement.

The user-facing result should normalize evidence into **TASK, DEADLINE, ANNOUNCEMENT, MESSAGE, EVENT, RESOURCE, FEEDBACK, CHANGE**. Today should show the actionable item and what changed, with a source link and uncertainty where needed; it should not expose a data-entry cockpit or claim school submission/grades that were not observed. Each collector must keep source identity, capture time, original evidence, update/deletion semantics, and an honest coverage/last-success state.
